# COMP9517 Bird Detection

Bird detection in natural beach environments
using YOLO and RT-DETR.

## Objectives
- Build reproducible bird detection pipelines
- Compare CNN-based and Transformer-based detectors
- Evaluate mAP@0.5, recall, and inference speed
- Investigate small and dense bird detection
- Analyse failures and improve model robustness

## Models
- YOLO11
- RT-DETR

## Dataset
Beach Bird Detection Dataset (Kaggle)
